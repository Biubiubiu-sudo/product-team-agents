# Product Team Agents

基于 Qoder 的**产品需求小组多智能体协作框架**，一键生成专业级 PRD 文档和 UI 设计提示词。

## 为什么选择 Product Team Agents？

- **专业团队协作**：5 个专业角色各司其职，模拟真实产品团队工作模式
- **全自动化流程**：从需求澄清到文档交付，全程自动协作，无需人工干预
- **高质量保障**：内置独立评审机制，确保输出的 PRD 可直接用于开发
- **智能追问**：不限次数追问，直到完全理解你的需求
- **知识沉淀**：越用越了解你的偏好和项目规则，配合越来越默契

## 角色介绍

### Product Owner（产品负责人）

**职责**：整个团队的协调者和指挥官

- 接收用户需求，进行初步理解和澄清
- 调度各专家按正确顺序执行任务
- 监控整体进度，确保按时交付
- 整合最终成果，输出完整交付物

### Requirement Analyst（需求分析师）

**职责**：需求的深度挖掘者

- 拆解功能模块，建立清晰的功能架构
- 编写用户故事，明确用户价值
- 梳理业务流程，绘制流程图
- 挖掘业务规则，确保逻辑完整
- 分析数据需求，定义数据模型
- 识别非功能需求（性能、安全等）

**输出**：
- 功能模块清单
- 用户故事集
- 业务流程图
- 业务规则说明
- 数据需求分析
- 非功能需求清单

### PRD Writer（PRD 专家）

**职责**：专业的产品需求文档撰写者

- 撰写产品概述和项目背景
- 定义用户角色和权限体系
- 详细描述每个功能模块的需求
- 设计接口规范和数据结构
- 规划版本迭代路线

**输出**：
- 产品概述文档
- 用户角色定义
- 功能模块详细需求（每个模块独立文档）
- 接口设计文档
- 版本规划

### UI Designer（UI 设计师）

**职责**：可落地的 UI 设计方案输出者

- 分析页面结构和导航逻辑
- 设计每个页面的布局和组件
- 输出可用于 AI 绘图工具的提示词
- 定义交互规范和视觉风格

**输出**：
- 页面结构分析
- UI 提示词（每个页面独立文档）
- 交互规范说明

### PRD Reviewer（评审专家）

**职责**：独立的质量把关者

- 评审 PRD 文档的完整性
- 检查需求的一致性和可执行性
- 验证 UI 设计与 PRD 的匹配度
- 输出评审报告和改进建议

**输出**：
- 评审报告
- 问题清单
- 改进建议

## 安装指南

### 方式一：全局安装（推荐）

```bash
# 克隆仓库
git clone https://github.com/Biubiubiu-sudo/product-team-agents.git
cd product-team-agents

# 复制智能体文件
cp agents/*.md ~/.qoder/agents/

# 复制知识文件
cp knowledge/*.md ~/.qoder/knowledge/
```

### 方式二：项目级安装

```bash
# 在你的项目根目录
mkdir -p .qoder/agents .qoder/knowledge

# 复制文件
cp /path/to/product-team-agents/agents/*.md .qoder/agents/
cp /path/to/product-team-agents/knowledge/*.md .qoder/knowledge/
```

### 安装可选 Skills（增强能力）

```bash
npx skills add context7 read-github docx pdf planner
```

详见 [skills/README.md](skills/README.md)

## 使用方法

在 Qoder 中直接描述你的需求：

```
我需要做一个项目管理系统，支持多部门协作...
```

或者直接调用产品负责人：

```
/product-owner 帮我分析一个电商平台的需求
```

**产品负责人会自动完成**：
1. 与你澄清需求（不限次数追问）
2. 调度需求分析师进行深度分析
3. 并行调度 PRD 专家和 UI 设计师
4. 调度评审专家进行质量把关
5. 整合输出完整交付物

## 知识沉淀

框架支持两种知识文件，越用越懂你：

### USER_PROFILE.md（用户偏好）

记录你的个人偏好，例如：
- 喜欢的文档风格
- 常用的技术栈
- 沟通方式偏好

### PROJECT_RULES.md（项目规则）

记录项目级别的规则，例如：
- 命名规范
- 技术约束
- 业务术语表

## 常见问题

### Q: 智能体没有出现在菜单中？

确保文件复制到了正确的位置：
- 全局：`~/.qoder/agents/`
- 项目级：`.qoder/agents/`

### Q: 可以只使用部分角色吗？

可以，但推荐使用完整流程以获得最佳效果。单独调用：
- `/requirement-analyst` - 只做需求分析
- `/prd-writer` - 只写 PRD
- `/ui-designer` - 只设计 UI

### Q: 如何自定义输出格式？

修改 `knowledge/` 目录下对应的工作手册文件。
