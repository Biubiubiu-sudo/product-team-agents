## 文档输出规范

### Markdown 格式约束

所有项目输出文档（PRD、需求分析、UI设计等）必须遵守以下格式规范，避免 markdownlint 警告：

#### 禁止使用的格式（会触发 MD036 警告）
```markdown
<!-- 错误示例 -->
- **关键词**：描述内容
- **功能名称**：功能说明
```

#### 正确格式
```markdown
<!-- 正确示例 -->
- 关键词：描述内容
- 功能名称：功能说明
```

#### 规则说明
- 列表项中不要使用 `**粗体**` + `中文冒号` 的组合
- 标题必须使用标准的 `# ## ###` 语法
- 需要强调时，可在正文中使用粗体，但不要与冒号连用作为列表项前缀
